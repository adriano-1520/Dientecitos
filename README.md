# Dientecitos 🦷
Atlas interactivo de anatomía dental para la carrera de Estomatología.

## Características
- **Corte Longitudinal del Diente (Estilo IMAIOS e-Anatomy):** Incluye las 16 estructuras anatómicas exactas (Cavidad de la corona, Esmalte, Dentina, Conducto radicular, Foramen apical, Ápex de la cúspide, Cúspide, Cresta marginal, Cresta triangular, Corona, Cara oclusal, Cuello, Diente, Cavidad pulpar, Raíz del diente y Ápex de la raíz).
- **Vistas adicionales:** Cara oclusal y Arco dental maxilar.
- **Pizarra Interactiva:** Soporte para ratón y pantallas táctiles para dibujar sobre el atlas.
- **Modo Quiz Anatómico:** Evaluación interactiva con puntaje en tiempo real.
